# FridgeFit website

Static pages for the App Store listing. No build step.

| Page | App Store Connect field |
|---|---|
| `index.html` | Marketing URL |
| `support.html` | Support URL (required) |
| `privacy.html` | Privacy Policy URL (required) |

Before publishing:
- Replace `SUPPORT_EMAIL@example.com` in `support.html` and `privacy.html`.
- Keep `privacy.html` in sync with the App Privacy answers in App Store Connect.
- Once the app is live, replace "Coming soon" on `index.html` with the App Store link and Apple's official badge.
